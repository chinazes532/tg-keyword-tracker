<h1 align="center">🔍 TG-Keyword-Tracker</h1>

<p align="center">
  <b>Система автоматического мониторинга Telegram-чатов по ключевым словам.</b><br>
  Решение на связке UserBot + Bot для работы в любых группах без прав администратора.
</p>

<hr />

<h3>📖 Описание</h3>
<p>
Проект предназначен для отслеживания упоминаний определенных услуг, товаров или тем в сторонних Telegram-чатах. 
<b>UserBot</b> выступает в роли "слушателя", а обычный <b>Bot</b> выполняет функции панели управления и рассылки уведомлений администраторам.
</p>

<h4>Пример уведомления:</h4>
<blockquote>
  🎯 <b>Найдено ключевое слово:</b> <code>работа</code><br>
  👤 <b>Отправитель:</b> Ivan<br>
  📍 <b>Чат:</b> Тестовый чат<br>
  📝 <b>Сообщение:</b> Ищу работу разработчиком
</blockquote>

<hr />

<h3>🛠 Стек технологий</h3>
<ul>
  <li><b>Язык:</b> Python 3.12+</li>
  <li><b>Библиотеки:</b> Telethon, Aiogram 3, SQLAlchemy, Alembic</li>
  <li><b>База данных:</b> PostgreSQL (через asyncpg)</li>
  <li><b>Инфраструктура:</b> Docker, Docker Compose</li>
</ul>

<hr />

<h3>🚀 Основной функционал</h3>
<p>Взаимодействие с системой происходит через интуитивное <b>клавиатурное меню</b> бота:</p>
<ul>
  <li>👥 <b>Управление админами:</b> добавление/удаление лиц с доступом к панели.</li>
  <li>🤖 <b>Настройка UserBot:</b> привязка аккаунта (API ID, Hash, телефон).</li>
  <li>💬 <b>Список чатов:</b> управление базой групп для мониторинга.</li>
  <li>🔑 <b>Ключевые слова:</b> гибкое управление списком отслеживаемых фраз.</li>
</ul>

<hr />

<h3>⚙️ Установка и запуск</h3>

<h4>1. Регистрация приложения</h4>
<ol>
  <li>Перейдите на <a href="https://telegram.org">my.telegram.org</a>.</li>
  <li>Создайте приложение в разделе <b>"API development tools"</b>.</li>
  <li>Получите <code>api_id</code> и <code>api_hash</code>.</li>
</ol>

<h4>2. Настройка окружения</h4>
<p>Скопируйте <code>.env.example</code> в <code>.env</code> и заполните переменные:</p>

<h4>3. Запуск</h4>
<pre><code>docker-compose up -d --build</code></pre>

<hr />

<h3>📊 Структура базы данных</h3>
<details>
<summary><b>Нажмите, чтобы развернуть схему моделей</b></summary>
<br>
<ul>
  <li><code>Admin</code> — хранит Telegram ID администраторов.</li>
  <li><code>Chat</code> — список отслеживаемых чатов (ID и заголовки).</li>
  <li><code>KeyWord</code> — база ключевых слов для поиска.</li>
  <li><code>UserBot</code> — конфигурационные данные аккаунта-слушателя.</li>
</ul>
</details>
